# Design System

## Typography

Geist

| Element | Grootte | Gewicht | Gebruik |
|---|---|---|---|
| `h1` | `48px / 3rem` | 700 | Hero tagline |
| `h2` | `36px / 2.25rem` | 600 | Sectie titels |
| `h3` | `24px / 1.5rem` | 600 | Project titels |
| `h4` | `20px / 1.25rem` | 500 | Case study subtitels |
| Body | `16px / 1rem` | 400 | Algemene tekst |
| Small | `14px / 0.875rem` | 400 | Tags, captions |

## Colors

| Token | Waarde | Gebruik |
|---|---|---|
| Background | `#0A0A0A` | Pagina achtergrond |
| Surface | `#111111` | Kaarten en secties |
| Border | `#222222` | Subtiele borders |
| Text primary | `#EDEDED` | Hoofdtekst |
| Text muted | `#888888` | Secundaire tekst |
| Accent | `#10B981` | Buttons, highlights |

## Spacing
